# QUALITY_CHECKLIST.md — Чек-лист для validate_content.cjs

Валидатор должен проверить **каждый** JSON-файл урока по этому списку.

## 1. Структура верхнего уровня
- [ ] Есть `lesson_id` (строка, не пустая)
- [ ] Есть `block` ∈ {"python_core", "sql_db", "web_api"}
- [ ] Есть `meta` с полями `title` (строка) и `topic_order` (число > 0)
- [ ] Есть `steps` (массив, не пустой)

## 2. Каждый шаг в `steps`
- [ ] Есть `step_id` (строка, уникальна в уроке)
- [ ] `phase` ∈ {"guided", "independent", "capstone"}
- [ ] `task_type` ∈ {"quiz", "table", "matching", "programming", "sql"}
- [ ] `points` ∈ {1, 5, 10, 20}
- [ ] `markdown_text` (строка, не пустая)
- [ ] `hint_levels` (массив из ровно 3 строк)

### 2.1 Поля по `task_type`
- **quiz**: есть `quiz_options` (массив ≥3 строк), есть `quiz_correct_index` (число 0..len-1)
- **table**: есть `table_rows` (массив ≥1, каждый объект имеет `label` и `expected_value`)
- **matching**: есть `matching_pairs` (массив ≥3, каждый объект имеет `left` и `right`)
- **programming**: есть `starter_code` (строка), есть `check_rules` (массив ≥1)
- **sql**: есть `starter_query` (строка), есть `expected_result_rows` (массив), есть `seed_schema_ref` (строка)

### 2.2 `tutorial_guidance` (только для `phase: "guided"`)
- [ ] Поле присутствует и не пустое
- [ ] **Количество слов**: 300–500 (после удаления Markdown-разметки, только текст)
- [ ] Минимум **2 фенс-блока кода** ```language ... ``` (разных по содержанию)
- [ ] Минимум **2 РАЗНЫЕ** частые ошибки (ищите паттерны "Ошибка:", "Правильно:", "Почему:" или аналогичные маркеры, не перефразировки)
- [ ] Нет многострочного кода вне фенс-блоков (проверка: нет строк с отступом > 0, не внутри ```...```)

### 2.3 Термины и стиль
- [ ] Ключевые слова/функции не переведены (`print()`, `list`, `def`, `if`, `for`, `while`, `JOIN`, `SELECT`, `WHERE` и т.д.)
- [ ] Тон преподавателя (проверка эвристическая: наличие обращений "ты", "мы", "давай", "посмотри")

## 3. Пропорции `independent` шагов (фаза `independent`)
Подсчитать шаги с `phase: "independent"` в уроке:
- [ ] `quiz` ≥ 3
- [ ] `table` ≥ 2
- [ ] `matching` ≥ 1
- [ ] `programming` + `sql` ≥ остальное (обычно 4-8)

## 4. Валидность JSON
- [ ] Файл парсится без ошибок
- [ ] Нет завершающих запятых в объектах/массивах
- [ ] Кодировка UTF-8

## 5. Игнорируемые пути
Валидатор **не проверяет** файлы внутри:
- `labs_protocols/_archive/`
- `labs_protocols/_dev_fixtures/`

## Вывод валидатора (CONSOLE)

Только две строки:
```
SUMMARY passed=X total=Y failed=Z
FAIL: path/to/file.json — краткая причина (одна строка)
```

Подробный отчёт → `labs_protocols/_validation_report.txt` (перезаписывается каждый запуск).
