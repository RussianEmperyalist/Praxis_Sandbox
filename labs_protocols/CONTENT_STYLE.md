# CONTENT_STYLE.md — Единый источник правды для протоколов уроков

## JSON-схема урока

Урок — **один линейный поток** шагов без разделения на режимы Tutorial/Practice. Теория и практика идут подряд в одном массиве `steps`.

```json
{
  "lesson_id": "python_core/01_numbers_strings",
  "block": "python_core",
  "meta": {
    "title": "Числа и строки",
    "topic_order": 1
  },
  "steps": [
    {
      "step_id": "step-1",
      "phase": "guided",
      "task_type": "quiz",
      "points": 1,
      "markdown_text": "Вопрос или условие задачи",
      "tutorial_guidance": "Теория 300-500 слов... (только для guided)",
      "hint_levels": ["Подсказка 1", "Подсказка 2", "Подсказка 3"],
      "quiz_options": ["Вариант А", "Вариант Б", "Вариант В"],
      "quiz_correct_index": 0
    }
  ]
}
```

## Обязательные поля для каждого шага

| Поле | Описание |
|------|----------|
| `step_id` | Уникальный в рамках урока идентификатор |
| `phase` | `guided` (обучение) \| `independent` (самостоятельная работа) \| `capstone` (итоговый проект) |
| `task_type` | `quiz` \| `table` \| `matching` \| `programming` \| `sql` |
| `points` | Вес: 1 (лёгкие quiz/table) \| 5 (matching) \| 10 (programming) \| 20 (capstone/sql) |
| `markdown_text` | Условие/вопрос на русском в Markdown |
| `tutorial_guidance` | **Обязателен для guided**, опционален для independent/capstone |
| `hint_levels` | Массив из 3 подсказок (от общей к конкретной) |

## Поля по типам задач

### quiz (одиночный выбор)
- `quiz_options`: массив строк (минимум 3 варианта)
- `quiz_correct_index`: индекс правильного ответа (0-based)

### table (заполнение таблицы)
- `table_rows`: массив объектов `{ "label": "Описание", "expected_value": "ответ" }`

### matching (сопоставление)
- `matching_pairs`: массив объектов `{ "left": "...", "right": "..." }` (минимум 3 пары)

### programming (написание кода)
- `starter_code`: начальный код (может быть пустой строкой `""`)
- `check_rules`: массив правил проверки (строки-описания или функции)

### sql (SQL-запросы, Блок 2)
- `starter_query`: начальный SQL (может быть пустым)
- `expected_result_rows`: ожидаемые строки результата
- `seed_schema_ref`: путь к JSON с тестовыми данными (например `"seeds/users.json"`)

## Требования к `tutorial_guidance` (guided-шаги)

1. **Объём**: **300–500 слов** (обе границы включительно). Считайте слова после рендера Markdown (без разметки).
2. **Примеры кода**: Минимум **2 разных примера** в блоках ```python ... ``` (или ```sql```). Никогда не пишите многострочный код инлайн — только в фенс-блоках!
   > ⚠️ **ПРАВИЛО-ПРЕДУПРЕЖДЕНИЕ**: Многострочный код ТОЛЬКО в ```language ... ``` блоках. Однострочный код в тексте допускается только для названий функций/переменных (например `print()`).
3. **Частые ошибки**: Минимум **2 РАЗНЫЕ** ошибки новичка (не перефразировки друг друга). Формат в тексте: «Ошибка: ... Правильно: ... Почему: ...»
4. **Термины**: Не переводить ключевые слова, функции, операторы (`print()`, `list`, `def`, `JOIN`, `SELECT`). Переводить только общие понятия.
5. **Тон**: Живой преподаватель, разговорный стиль, без калек с английского («реализовать» → «сделать/написать», «инициализировать» → «создать/задать»).

## Пропорции task_type на independent-часть

Для каждого урока в фазе `independent` (исключая guided и capstone):

| task_type | Минимум | Вес (points) |
|-----------|---------|--------------|
| `quiz` | 3 | 1 |
| `table` | 2 | 1 |
| `matching` | 1-2 | 5 |
| `programming` / `sql` | остальные | 10 / 20 |

Итого шагов `independent`: обычно 10-15. Сумма весов определяет максимальный балл за урок.

## Пример guided-шага (фрагмент)

```json
{
  "step_id": "step-1",
  "phase": "guided",
  "task_type": "quiz",
  "points": 1,
  "markdown_text": "Что выведет `print(3 + 4 * 2)`?",
  "tutorial_guidance": "В Python работает привычный порядок операций: умножение и деление выполняются раньше сложения и вычитания. Это значит, что `4 * 2` посчитается первым, а потом к результату прибавится `3`.\n\n```python\nprint(3 + 4 * 2)  # 11\n```\n\nСкобки меняют порядок:\n\n```python\nprint((3 + 4) * 2)  # 14\n```\n\n**Ошибка 1**: Начинают считать слева направо: `3 + 4 = 7`, потом `7 * 2 = 14`. Правильно: сначала умножение. Почему: у `*` и `/` приоритет выше, чем у `+` и `-`.\n\n**Ошибка 2**: Думают, что скобки нужны всегда. Правильно: скобки нужны только когда хотите изменить стандартный порядок. Почему: лишние скобки читаются дольше и не дают пользы.",
  "hint_levels": [
    "Вспомни порядок действий в математике",
    "Умножение делается раньше сложения",
    "Сначала 4 * 2 = 8, потом 3 + 8 = 11"
  ],
  "quiz_options": ["11", "14", "7"],
  "quiz_correct_index": 0
}
```
